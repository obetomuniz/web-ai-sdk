# Security policy

## Supported versions

Security fixes target the latest published version of each `@web-ai-sdk/*`
package. Older versions do not receive separate security backports. Upgrade to
the latest version when a fix is available.

Reports about the current documentation site and public MCP server are also
welcome.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/obetomuniz/web-ai-sdk/security/advisories/new)
to report a suspected vulnerability. Do not include vulnerability details in
public issues, discussions, or pull requests.

Include:

- The affected package and version, or the affected site or MCP endpoint.
- Your browser, operating system, and relevant configuration.
- Steps to reproduce the issue and a minimal example.
- The expected behavior, actual behavior, and potential security impact.
- A suggested fix, if you have one.

Remove credentials, personal information, and unrelated private data from
examples and logs. Use accounts and data you control for reproduction.

Use the private report to coordinate a fix and public disclosure with the
maintainer. Response and resolution times depend on the report and maintainer
availability.

For ordinary bugs and feature requests, use
[GitHub issues](https://github.com/obetomuniz/web-ai-sdk/issues).
