web-ai-sdk

Building blocks for the Web's built-in AI APIs.

Composable. No runtime deps. Just lifecycle, streaming, and AbortSignals. Vanilla TypeScript by default, with optional React hooks.

Get started → ◇ View on GitHub $ npm install web-ai-sdk/all
